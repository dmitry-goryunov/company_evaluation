# Security policy

## Supported version

Security fixes are applied to the latest revision of the default branch. Historical exports under
`legacy/` are not maintained.

## Reporting a vulnerability

Use the repository's private **Security advisories → Report a vulnerability** flow. Do not disclose
credentials, confidential source material, MNPI or an exploitable issue in a public issue.

Include the affected path or workflow, reproduction steps, impact and any suggested mitigation. Do
not include live secrets. Revoke any exposed credential before reporting it.

## Research-workspace safety

Keep company source workspaces separate from this repository when they contain confidential or
MNPI-sensitive material. The ignore rules are defence in depth, not permission to store secrets in
the repository.
